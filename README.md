# Munise Haruyama Portfolio

UI/UX デザイナー・フロントエンドエンジニア Munise（むにせ）のポートフォリオサイト。日本語 / 英語（`/en`）に対応。

## Tech Stack

- Next.js 16 (App Router) / React 19 / TypeScript
- Tailwind CSS v4
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

http://localhost:3000 で確認できる。

## Structure

```
src/
├── app/         # ページ（トップ・/career・/design・/projects/[id]・/en）
├── components/  # UIコンポーネント
├── data/        # プロジェクト・キャリアデータ
└── i18n/        # 日本語 / 英語のテキスト
```
